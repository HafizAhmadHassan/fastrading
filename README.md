# Fastrading
*Created: 2024-09-27*

A Python **algorithmic trading** library built with **nbdev**.

## Overview

Fastrading provides building blocks for algorithmic / automated trading. It integrates **Lumibot** for executing trading strategies and organises its code as a proper Python package developed with the nbdev workflow.

## Repository Structure

```
├── fastrading/    # Core Python package
└── nbs/           # nbdev notebooks (development source)
```

## Features

- Algorithmic trading helpers
- Lumibot integration for automated trading
- nbdev-driven package development

## Tech Stack

Python, nbdev, Lumibot, finance / quant.

## Status

Active library project.
